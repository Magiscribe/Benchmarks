# AI Spy Data Directory

This directory contains the output data from the AI Spy benchmark.

## Directory Structure

- `responses/`: Contains raw model responses to benchmark images
  - Format: `{model_name}_responses.json`
  - Example: `claude-3-haiku_responses.json`
  
- `results/`: Contains processed evaluation results for each model
  - Format: `{model_name}_results.json`
  - Example: `claude-3-haiku_results.json`
  
- `visualizations/`: Contains generated charts and visualizations
  - Generated by the visualizer script from the results data
  - Contains font accuracy and font size accuracy charts

## Using the Visualizer

To generate visualizations from all results:

```bash
# Using the Python script directly
python visualizer.py --data-dir data

# Or using the shell script
./run_visualizer.sh
```

The visualizer will automatically find all result files in the `results/` directory and generate visualizations in the `visualizations/` directory.
